A complete, end-to-end trailer automation suite for **Jellyfin Media Server**, featuring:
1. **Server Plugin (`Jellyfin.Plugin.CustomHoverTrailer`)**: Injects dynamic hover trailer video previews directly into the Jellyfin Web UI.
2. **Companion Studio (`TrailerGenerator.WinForms`)**: A feature-rich Windows application for batch scanning, FFmpeg timeline analysis (scene cuts, audio loudness, visual motion), interactive manual timeline editing, automated folder watching, and scheduled background trailer generation.

## 1. Jellyfin Server Plugin

The **Custom Hover Trailer Plugin** integrates into Jellyfin Media Server and injects client-side scripts to deliver Netflix-style hover previews across library views.

### How It Works
- **Web Client Injection**: Uses `WebClientInjectorHostedService` to inject `hoverTrailer.js` into Jellyfin's web client DOM.
- **Local Trailer Priority**: Detects existing `*-trailer.mp4` files located in the same directory as the movie file (as generated by the companion app).
- **Remote Fallback**: If no local trailer exists, queries YouTube via `YoutubeExplode` to stream official promotional trailers.
- **Responsive Card Overlay**: On mouse hover (or long press on touch devices), smoothly loads and loops video previews within the poster card with configurable delays, volume levels, and audio muting.

### Plugin Features
- **Configurable Hover Delay**: Prevents unintentional playback while quickly scrolling through libraries.
- **Sound & Volume Controls**: Configurable mute-by-default, initial playback volume, and hover sound effects.
- **Card Sizing & Layout Matching**: Adapts seamlessly to standard poster cards, thumb cards, and banner views.
- **Web Admin Dashboard**: Manage plugin settings and logging directly through the Jellyfin Dashboard.

### Plugin Installation
1. Compile the solution in `Release` mode using the .NET 9 SDK:
   ```powershell
   dotnet build src/Jellyfin.Plugin.CustomHoverTrailer/Jellyfin.Plugin.CustomHoverTrailer.csproj -c Release
   ```
2. Copy `Jellyfin.Plugin.CustomHoverTrailer.dll` and `YoutubeExplode.dll` from `bin/Release/net9.0/` into your Jellyfin server's `plugins/CustomHoverTrailer/` folder.
3. Restart the Jellyfin service.
4. Navigate to **Dashboard -> Plugins -> Custom Hover Trailer** to configure preferences.

## 2. Desktop Companion Studio (Trailer Generator)

`TrailerGenerator.WinForms` is a high-performance .NET 9 desktop application designed to create polished, high-definition trailer video clips (`*name_of_video*-trailer.mp4`) matching Jellyfin's naming conventions.

### Core Generation Modes
The generator splits videos into scenes and extracts highlights according to three intelligent algorithms:

| Generation Mode | Description | How Highlight Moments Are Selected |
| :--- | :--- | :--- |
| **1. Random** | Splits the movie into uniform scene intervals and picks random timestamps within each scene. | Random selection within each detected scene boundary. |
| **2. Sound Detect** | Analyzes audio volume using FFmpeg's `ebur128` filter. | Finds the **loudest moment** in each scene and centers the snippet around that peak. |
| **3. Movement Detection** | Analyzes frame-by-frame visual changes using FFmpeg's scene motion filter. | Detects the **highest-action sequence** in each scene and centers the snippet on peak motion. |

#### Trimming & Usable Video Range
To prevent movie intros, logos, credits, and post-credits scenes from entering the trailer, configure:
- **Start Skip**: Skip by percentage (e.g., first 10%) OR fixed seconds (e.g., first 120 seconds).
- **End Skip**: Skip by percentage (e.g., last 10% of the film).
- Applies uniformly across all three generation modes.

---

### Video Library Management

The main window provides a modern, responsive data grid for managing and monitoring video collections:

- **Sortable & Filterable Columns**:
  - `Generate`: Checkbox with **Shift + Click** multi-row selection for quick batch selection.
  - `Source Video`: File name of the movie.
  - `Target Trailer File`: Output `*-trailer.mp4` path in the source folder.
  - `Mode`: Generation mode (`Manual` vs `Automatic`).
  - `Analysis`: Displays probed status:
    - `Full (Scenes, Audio, Motion)`: All analysis tracks ready.
    - `Scenes, Audio` / `Motion`: Partial analysis indicator.
    - `Presets Only (N)` / `Not Analyzed`: Current analysis state.
    - `| Configs: Preset_Names`: Displays saved configuration presets.
  - `Status`: Live status (`Missing Trailer`, `Done ✓`, `Exists (Skipped)`, `Analysis Ready`, `Trailer Deleted`).
  - `Folder Path`: Library directory path.
- **Filter Bar**: Real-time text search filtering across file names, folders, and analysis tags, plus status filters (`All`, `Missing Trailers`, `Existing Trailers`, `Manual Mode Only`, `Automatic Mode Only`, `Analyzed Only`, `Unanalyzed Only`).
- **Right-Click Context Menu**:
  - `🔍 Analyze Selected Video(s)`: Pre-computes and caches timeline analysis in batch.
  - `🗑️ Delete Trailer File(s)`: Permanently deletes existing `*-trailer.mp4` files with confirmation.
  - `✏️ Open in Manual Editor`: Opens the manual editing suite for fine-tuning.
- **Parallel Batch Processing**: Configurable multi-process concurrency (`Parallel.ForEachAsync`) bounded by user settings, with live progress bars and cancel support.

---

### Interactive Manual Trailer Editor

Double-clicking any movie row opens the **Manual Trailer Editor**:

- **Smooth 24 FPS Preview**: Hardware-accelerated continuous video streaming via FFmpeg pipes directly into a high-DPI WinForms viewport.
- **Synchronized 16-Bit PCM Audio**: Native playback through Windows `waveOut` APIs with zero buffer stutter or timeline drift.
- **Responsive Viewport Scaling**: Percentage-based row geometry ensures the video player expands dynamically when maximizing or resizing the window.
- **Volume Slider & Mute Toggle**: Dedicated volume trackbar (`0–100%`) with in-place PCM sample scaling and mute toggle.
- **5 Stacked Visual Timelines**:
  1. **Detected Scenes**: Visualizes scene cut boundaries across the film.
  2. **Sound Detect**: Shows audio peak timestamps computed via loudness analysis.
  3. **Movement Detection**: Shows peak motion timestamps computed via optical scene scoring.
  4. **Random Points**: Visualizes random timestamps with a one-click **"🎲 Regenerate Random"** button.
  5. **Manual Segments**: Interactive track where segments can be dragged, resized, and added directly at the scrubber position.
- **Fine-Tuning Controls**: Numeric controls for segment start time and duration, segment deletion, and total trailer duration readouts.
- **Preset Configurations**: Save multiple configurations per video (e.g., `SoundDetect_60s`, `MovementDetection_90s`). Re-opening a video reuses cached analysis instantly without re-probing.
- **High-Contrast Reset Button**: A distinct, high-contrast **"Reset to Auto Mode"** button with protective confirmation prompts and tooltips.

---

### Synchronized Side-by-Side Comparison

When editing a movie that already has an existing `*-trailer.mp4`:
- Check **"🔀 Compare Existing Trailer"** to split the viewport 50% / 50%.
- **Independent Existing Trailer Player**: Dedicated play/pause button, independent scrubber, timestamp display, and trailer mute toggle.
- **Simultaneous Dual Playback**: Clicking the main **"▶ Play Preview"** button starts both players simultaneously:
  - **Right Player**: Plays the existing trailer continuously from its current position.
  - **Left Player**: Sequences through the new manual segments in chronological order, jumping between clips.
  - **Duration Disparity Handling**: If the new trailer is longer than the existing one, the existing trailer cleanly holds its final frame while the new trailer continues playing until all segments complete.

### Background Library Monitoring

In the **Application Settings** dialog (`⚙ Settings`):
- **Folder Watcher Engine**: A background `FileSystemWatcher` pool monitoring configured library folders.
- **Smart Filtering**: Automatically ignores temporary download files (`.tmp`, `.crdownload`, `.part`) and existing `-trailer.*` files.
- **Debounced Arrival**: Configurable debounce delay (default `15s`) ensuring files are completely written and unlocked before processing.
- **Auto-Generation Trigger**: If enabled, automatically queues and generates a trailer in the background whenever a new movie is detected.

---

### Automated Scheduled Library Scans

Configure recurring background checks to keep collections up to date:
- **Frequency**: Run `Daily` or `Weekly`.
- **Day & Time**: Select Day of the Week (e.g. `Monday`) and 24-hour time (e.g. `03:00 AM`).
- **Deduplication Guard**: Enforces a 2-minute deduplication window against `LastScheduledRunUtc` to prevent repeated runs.
- **Automated Processing**: Scans library folders, detects newly added movies missing trailers, and runs trailer generation automatically using existing options.

---

### Configuration & Analysis Caching

All application states are persisted to `trailer-generator-state.json` in the application directory:
- Watched library folder lists.
- Generation mode settings, duration, skip percentages, and resolution scaling.
- Default preview volume and background watcher settings.
- Scheduled library check configuration and execution timestamps.
- **Cached Timeline Analyses**: Probed scene cuts, motion scores, and loudness peaks are stored per movie path to make future editor sessions load instantly without expensive re-analysis.
- **Saved Configurations**: Mode presets and manual segment slices per movie.

## Building from Source

### Prerequisites
- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- [FFmpeg](https://ffmpeg.org/download.html) (included with Jellyfin Server or installed on system `PATH`)

### Build Instructions
```powershell
# Clone repository
git clone https://github.com/ionuttheking-blip/CustomHoverTrailerPluginForJellyfin.git
cd CustomHoverTrailerPluginForJellyfin

# Build entire solution in Release configuration
dotnet build JellyfinTrailerSuite.sln -c Release --warnaserror

# Run automated tests and integrity checks
powershell -ExecutionPolicy Bypass -File .agent/skills/factory/scripts/run_project_tests.ps1
```
